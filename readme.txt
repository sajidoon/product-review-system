A complete product review and comparison system with custom templates, ratings, pros/cons, and price comparison.

== Description ==

Advanced Product Review System transforms your WordPress posts into professional product reviews. It allows you to add detailed ratings, specifications, pros/cons lists, and price comparisons from multiple stores.

**Key Features:**
*   **Detailed Ratings:** Add multiple rating criteria with progress bars.
*   **Pros & Cons:** Display bulleted lists of advantages and disadvantages.
*   **Price Comparison:** Show prices from different stores with "Buy Now" buttons.
*   **Specifications:** Add technical specs in a structured format.
*   **Custom Templates:** Choose from 3 distinct layouts (Review, Comparison, Minimal) or use your theme's default.
*   **Global Settings:** Set a default template for all your reviews.

== Installation ==

1.  Upload the plugin files to the `/wp-content/plugins/product-review-system` directory.
2.  Activate the plugin through the 'Plugins' screen in WordPress.
3.  Go to any Post and scroll down to the "Advanced Product Information" meta box to start adding review data.
4.  Go to **Review Settings** in the main sidebar to configure styles and default templates.

== Documentation ==

= Using the Meta Boxes =
When editing a post, you will see a large section at the bottom:
*   **Ratings:** Add as many criteria as you want (e.g., Performance, Build Quality, Value).
*   **Specifications:** Table format specifications for technical products.
*   **Pros & Cons:** Bullet points for quick evaluation.
*   **Price Comparison:** Add multiple store URLs and prices.

= Template Selection =
On the right-hand sidebar of the post editor, use the "Post Template" box:
1.  **WordPress Default:** Uses your theme's `single.php`.
2.  **Product Review Template:** Standard clean review layout.
3.  **Product Comparison Template:** Wide layout optimized for specs comparison.
4.  **Minimal Review Template:** Slim design for short reviews.

= Global Styling =
Access the **Review Settings** menu to:
*   Change Primary and Primary colors.
*   Adjust Border Radius for a rounded/square look.
*   Set Typography and Background colors.
*   Configure Box Model (Margins and Padding).

== Frequently Asked Questions ==

= How do I reset all styles? =
Go to **Review Settings** and click the **Reset to Defaults** button.

= Where do I find the settings? =
The settings are available in the main WordPress sidebar under the **Review Settings** icon.
